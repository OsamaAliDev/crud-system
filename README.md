## Overview

This project is a simple CRUD application for managing products. It includes features such as:

- Add new products with image preview support
- Edit existing products
- Delete products
- Search products by name, type, category, SKU, and description
- Persistent data storage using `localStorage`
- Responsive and futuristic user interface

## How to Use

1. Open `index.html` in a browser.
2. Enter product details in the form below the table.
3. Choose an image file to preview it before saving.
4. Use the search box to filter product entries.
5. Click `Edit` to load product data into the form and update it.
6. Click `Delete` to remove a product from the list.

## Project Structure

- `index.html` - Main application page
- `css/style.css` - Custom styling for the app
- `js/main.js` - CRUD logic and form validation
- `assets/` - Additional assets for the project

## Notes

This project is designed as a lightweight front-end CRUD demo that works entirely in the browser without a backend server.
